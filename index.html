Статьи движения денег

Выберите для статьи один способ: начисления 1С или оплаты по банку.

Настройки сохраняются в этом браузере для текущей базы. Для учёта по банку включите галочку и выберите соответствующую статью расходов 1С. До выбора связи действует учёт по начислению. Зарплата и отчисления работодателя — только по начислениям. Данные в 1С не меняются. Ранее поставленные галочки требуют настройки связи статей.
